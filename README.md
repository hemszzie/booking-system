# Expert Session Booking System

A real-time expert booking platform built using:

- React.js
- Node.js
- Express.js
- MongoDB
- Socket.io
- Tailwind CSS

## Features

- Expert listing
- Search & filter
- Pagination
- Real-time slot updates
- Double booking prevention
- Booking management
- Responsive UI

## Tech Stack

Frontend:
- React
- Tailwind CSS
- Axios
- Socket.io Client

Backend:
- Node.js
- Express.js
- MongoDB
- Mongoose
- Socket.io

## Run Locally

### Backend

cd server
npm install
npm run dev

### Frontend

cd client
npm install
npm run dev
